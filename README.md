An entry for make.fun's "Have You Tried Turning It Off?" bounty: `main.py` checks one support-agent line against the house gate (UTF-8, a single line, 1 to 199 characters) and writes it to `/output/entry.txt` with no trailing newline. That one line \u2014 an escalation that ends with the agent worried too \u2014 is the entire entry.

## How to run

```sh
python3 main.py
```

The script prints how many characters it wrote. It needs nothing beyond Python 3 and the standard library.
